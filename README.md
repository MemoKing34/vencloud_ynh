## Overview

Vencloud is the official backend used by [Vencord](https://vencord.dev), the Discord client mod, to sync your settings across devices. Self-hosting it means your Vencord settings never leave your own server.

### Features

- Cloud backup and synchronization of Vencord settings across all your Discord clients
- Authentication through Discord OAuth2 — no extra account needed
- Optional whitelist of Discord users allowed to use the instance
- Lightweight: a single Go binary and a dedicated Redis instance

**Shipped version:** 0.0.2~ynh1
